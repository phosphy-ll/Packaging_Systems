# Packaging Systems

Корпоративный B2B-сайт и управляемый каталог оборудования для розлива и упаковки. Основан на материалах Packaging Systems, предоставленных для проекта.

## Возможности

- Адаптивный публичный сайт: главная, направления, сервис, контакты и каталог.
- «Сейчас в продаже»: поиск, фильтры, пагинация и карточки с характеристиками.
- Встроенная админка Django: товары, категории, фотогалереи, документы, информационные страницы и входящие заявки.
- Статусы: черновик / опубликовано / архив; наличие: в наличии / под заказ / продано. Скрытые товары не видны посетителям.
- Заявка с привязкой к оборудованию: сохраняется в базе и, если настроен SMTP, отправляется на **info@packaging.kz**.
- PostgreSQL в Docker, SQLite для локальной разработки, WhiteNoise для статики, Nginx для загруженных медиа.
- Тесты для публикации, просмотра товаров и обработки запросов.

## Локальный запуск (Python 3.12+)

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Установите в .env: DJANGO_DEBUG=1 и свой DJANGO_SECRET_KEY
python manage.py migrate
python manage.py seed_content
python manage.py createsuperuser
python manage.py runserver
```

Откройте http://127.0.0.1:8000/ и http://127.0.0.1:8000/admin/.

В Windows вместо `cp` используйте `copy .env.example .env`.

## Docker Compose

```bash
cp .env.example .env
# Установите надёжные DJANGO_SECRET_KEY и POSTGRES_PASSWORD
docker compose up --build -d
docker compose exec web python manage.py createsuperuser
```

Локальный сайт: http://localhost:8080/. Админка: http://localhost:8080/admin/.

**Внимание:** Docker-конфигурация слушает HTTP для разработки и тестового стенда. Для публичного сайта нужны HTTPS/TLS на внешнем reverse-proxy, корректные `ALLOWED_HOSTS`, `CSRF_TRUSTED_ORIGINS`, резервные копии БД и медиа, а также рабочий SMTP. Не публикуйте пароли и `.env` в GitHub.

### Как добавить товар

1. Войдите в `/admin/` аккаунтом суперпользователя.
2. Откройте «Категории» и при необходимости создайте категорию.
3. В «Товары» нажмите «Добавить»; заполните заголовок, категорию, описание и характеристики.
4. Ниже загрузите любое количество фотографий и PDF-спецификаций.
5. Выберите «Опубликован» и «В наличии» или «Под заказ», сохраните. Карточка появится в каталоге. Для снятия с продажи поставьте «Продано», «Архив» или «Черновик».

Админка позволяет редактировать содержимое информационных страниц и отслеживать обращения.

## Электронная почта

Укажите в `.env`:

```dotenv
EMAIL_HOST=smtp.example.com
EMAIL_PORT=587
EMAIL_HOST_USER=...
EMAIL_HOST_PASSWORD=...
EMAIL_USE_TLS=1
DEFAULT_FROM_EMAIL=info@packaging.kz
```

Пока SMTP не настроен, входящие **всё равно сохраняются** в разделе «Заявки» админки. В режиме разработки письма выводятся в терминал. На production используйте реальный SMTP.

## Материалы и фактчекинг

- Тексты разделов взяты из предоставленных DOCX.
- Контакты: info@packaging.kz, Алматы, Казахстан (сверены с packaging.kz).
- В разделе «Сейчас в продаже» **нет автоматически опубликованных товаров**. В презентации «Линия розлива 8 000 бут.» встречаются 8 000 бут/ч (заголовок) и 10 000 бут/ч (спецификация Bertolaso); перед публикацией данных нужна проверка. Черновик предложения создаётся командой `python manage.py seed_content`; его можно дополнить фото и опубликовать из админки.
- Раздел «Системы водоподготовки» создан с нейтральным текстом, поскольку подробное описание не было предоставлено.


## Структура

`config/` - конфигурация Django; `catalog/` - бизнес-логика, админка, шаблоны, статика; `catalog/management/commands/seed_content.py` - исходные тексты и черновик оборудования; `nginx/` - отдача медиа. Загружаемые фотографии и PDF сохраняются **в медиа-хранилище**, а не в Git.

## До публикации

Настройте домен/HTTPS, безопасный SMTP, постоянное хранилище медиа, бэкапы, мониторинг, политику обработки данных и уточните технические параметры первого предложения. Это рабочая основа сайта, а не подтверждение завершённого production-развёртывания.
